# Jad El Harake — Portfolio

Static one-page portfolio website built with HTML, CSS and JavaScript and structured for GitHub Pages.

## Preview locally

Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish on GitHub Pages

1. Create a public GitHub repository named `portfolio`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will publish it at `https://YOUR-USERNAME.github.io/portfolio/`.
